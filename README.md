# Backend para mensageria com IA utilizando vários provedores e fontes de prompts
## Descrição
Backend em dotnet criado para aprendizado</br>
## Funcionamento
1. Recebe mensagens do Telegram via bot.
2. Rotas post permitem o recebimento de mensagens através de requisições externas (utilizado no [frontend Angular](https://github.com/JPCassimiro/angular_gemini_frontend)
3. Utilização de diversos provedores de IA permite que o usuário escolha o provedor e modelo.
## Desenvolvimento
1. Arquitetura simples e direta.
2. Utilização de padrões de design inspirados em Factory permitem a integração de inúmeros provedores de forma rápida.
